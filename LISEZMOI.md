# Description
Le projet 3N2_BlocNoteProject est un projet visant à la création d'une application Android qui permet la création et sauvegarde de notes.
Les notes sont gardé dans l'application et peuvent être modifié ou supprimé à tout moments. L'application permet aussi l'importation de texte vers des nouvelles notes.

# Guide de compilation et d'éxécution

Le projet 3N2_BlocNoteProject est un projet Android développé sur Android Studio. Le logiciel est gratuit avec un compte Google et est obtenable sur
le site web d'[Android Studio](https://developer.android.com/studio). Après installation, il vous sera nécéssaire de télécharger mon projet sur GitHub
à l'adresse suivante: [3N2_BlocNoteProject](https://github.com/darkcdb/3N2BlocNoteProject), après téléchargement, ouvrez le fichier du projet via Android studio.
Depuis le projet ouvert, il vous sera disponnible de lancer soit un émulateur ou de connecter un appareil android à votre ordinateur par fil ou par wifi.
Après cela l'éxécution du projet deviendra possible.
